## Exact values

- CORS: erlaubte Origins `https://opteamanta.netlify.app`, `http://localhost:5173`, `http://localhost:4173`.
- `start-run`: Auth-Pflicht (JWT der anonymen Sitzung); Rate-Limit via `rate_counters` (Bucket `start`, Berliner Tag, ≤ 30); Antwort `{ sessionId, seed, mapId, mode: 'challenge', gameVersion, expiresAt }`. Die Karte bestimmt `new Game({ seed })`.
- `submit-run`: Auth; `checkSubmission`; Insert `pending`; Session `used_at`; `fetch(verify-runs)` ohne auf das Ergebnis zu warten (`EdgeRuntime.waitUntil`); Antwort `{ submissionId, status: 'pending' }`.
- `verify-runs`: nur mit Header `x-verify-secret = VERIFY_SECRET`; `claim_submission()` → `runReplay` → `finish_submission`; Antwort `{ id, status, cpuMs }`; `matches=false` → `rejected` mit „Ergebnis stimmt nicht“; Exception → Versuch zählt, nach 3 Versuchen `rejected` mit „Prüfung fehlgeschlagen“.
- `verify_jwt`: `start-run`/`submit-run` true, `verify-runs` false (eigenes Geheimnis).
