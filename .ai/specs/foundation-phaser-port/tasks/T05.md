# T05: Phaser-Spielfeld

**Phase:** 3 · **Depends on:** T02 · **Covers:** AC-11, AC-12 · **Who:** hannibal

## Goal

Phaser 4 rendert das Spielfeld optisch gleichwertig zum Original und steuert die Simulation
über einen Fixed-Step-Loop. Eingaben werden zu `Command`s.

- New: `src/view/GameScene.ts`, `src/view/loop.ts`, `src/view/render/board.ts`, `src/view/render/entities.ts`,

- Change: `src/main.ts`
- Read only: `tower-defenese-opTEAManta-v2.html` (Zeichnen: Zeilen 257–334; Texte: 81–98, 140–141, 196)

## Interfaces

```ts
// src/view/controller.ts – einzige Brücke zwischen DOM-HUD, Szene und Sim
export class Controller {
  game: Game; speed: 1 | 2 | 3 | number; selected: TowerType | null; selectedTowerId: number | null;
  constructor(opts: { seed: number; mapId?: MapId });
  command(cmd: Command): SimEvent[];  // leitet an game.apply weiter und verteilt Events
  advance(realDtSec: number): void;    // Fixed-Step: acc += min(realDt, 0.1)·speed; while acc ≥ DT && steps < 120: step
  restart(): void;                     // neuer Seed, neues Game
  on(listener: (e: SimEvent) => void): () => void;
}
```

## Exact values

- Phaser-Konfiguration: 960 × 600, `Phaser.Scale.FIT`, `autoCenter: CENTER_BOTH`, Parent `#game`, Hintergrund `#fbfbf7`.
- Darstellung je Element wie Original (Farben, Größen: Post-it 30 px, Boss 54 px, Turm Ø 34/26 px, Pfad 32 px breit, HSL der Karte).
- Kosmetischer Zufall nur in `src/view/` (`Math.random`).
- Ereignis-Mapping: `killed` → Konfetti + Spruch aus `KILL`; `leaked` → Rotblitz 0.25, Shake 12, Spruch aus `LEAK`;
  Boss-Kill → Shake 25, Flash 0.5, Text „PI-OBJECTIVE ERREICHT! (Business Value: 3 von 10)“; `jammed` → grauer Ring + Spruch;
  `absent` → „Klausurphase!“ usw.; `upgraded` → Stufentitel wie Original Zeile 196; `gameOver` → BURNOUT-Overlay.
