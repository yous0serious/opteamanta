# T06: DOM-HUD, Audio, Ticker, Replay-Export

**Phase:** 3 · **Depends on:** T05 · **Covers:** AC-10, AC-11 · **Who:** hannibal

## Goal

Seitenleiste, Info-Panel, Buttons, Tastatur, Ticker und Sound funktionieren wie im Original;
der letzte Lauf ist als Replay exportierbar.

## Files

- New: `src/view/hud.ts`, `src/view/audio.ts`, `src/view/input.ts`, `src/view/params.ts`
- Change: `index.html`, `src/view/style.css`, `src/main.ts`

## Exact values

- DOM-IDs aus dem Original bleiben: `#money`, `#lives`, `#wave`, `#score`, `#map`, `.tw[data-t]`, `#info`, `#big`, `#spd`, `#mute`, `#tk`;
  `data-t` nutzt die neuen Turm-IDs. Neu: `#replay` (Button „💾 Replay“, sichtbar nach Game Over).
- Tasten: `1`–`5` Turm wählen, `u` Upgrade, `s` Verkaufen, Leertaste Sprint starten bzw. nach Game Over neu,
  `Escape` Auswahl aufheben; Rechtsklick auf das Spielfeld = Abbrechen.
- HUD-Aktualisierung alle 0.2 s und sofort nach Kommandos.
- Audio: Original Zeilen 100–117 1:1 (Sounds an Events statt an Funktionen gebunden). Start erst nach erster Nutzergeste.
- Replay: nach `gameOver` und bei Neustart in `localStorage['bd.lastReplay']` speichern; `#replay` lädt `backlog-defense-replay-<seed>.json` herunter.
- URL-Parameter (`src/view/params.ts`): `seed` (uint32, sonst zufällig via `crypto.getRandomValues`), `map` (MapId),
  `speed` (1–10, Standard 1). Im Dev-Modus oder mit `?debug=1`: `window.__bd = controller`.

## Verify

`npm run build`; manuell alle Punkte aus AC-11 durchklicken; Replay herunterladen und `npm run replay -- <datei>` → Exit 0.
