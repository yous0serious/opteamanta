# T03: Bot, Replay-CLI, Benchmark

**Phase:** 2 · **Depends on:** T02 · **Covers:** AC-10, AC-13 · **Who:** hannibal

## Goal

Ein deterministischer Bot spielt lange Läufe headless; `npm run replay` prüft Replay-Dateien;
`npm run bench` misst die Nachrechenzeit (Grundlage für die Edge-Function-Entscheidung in Spec 3).

## Files

- New: `tools/bot.ts`, `tools/replay-cli.ts`, `tools/bench.ts`

## Interfaces

```ts
// tools/bot.ts
export function playBot(opts: { seed: number; maxWave: number }): Game; // spielt bis Game Over oder maxWave abgeschlossen
```
CLI: `npm run replay -- <pfad.json>` → Ausgabe `wave=<n> lives=<n> score=<n> tick=<n> hash=<h> matches=<true|false>`;
Exit-Code 0 bei `matches`, 1 bei Abweichung, 2 bei ungültiger Datei.
`npm run bench` → `seed=12345 waves=<n> ticks=<n> score=<n> ms=<n> ms_per_1k_ticks=<n>`.

## Pseudo code

Bot (keine Zufallsquelle außer der Sim selbst): vor jeder Welle in Schleife
1. Wenn Geld ≥ Kosten des nächsten Turms der Rotation `[dualo, dev, analyst, ppl, scrum, dev]`: auf die erste freie
   Zelle mit kleinstem Abstand zum Pfad-Mittelpunkt (Index `floor(path.length/2)`) platzieren, Gleichstand nach `cy`, dann `cx`.
2. Sonst den Turm mit den niedrigsten Upgrade-Kosten upgraden, falls bezahlbar.
3. Sonst `startWave`, dann `step()` bis die Welle beendet oder Game Over ist.

## Verify

`npm run bench` gibt eine Zeile aus; `npm run replay -- .tmp/bot-replay.json` (vom Bot erzeugt) → Exit 0; dieselbe Datei mit verändertem `result.score` → Exit 1.
