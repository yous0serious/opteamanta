export type MapId = 'spaghetti' | 'waterfall' | 'release-train' | 'matrix';

  rate?: number; dmg?: number; dps?: number; splash?: number; aura?: number; push?: number; color: string }
export interface EnemyDef { id: EnemyType; name: string; emoji: string; hp: number; speed: number; reward: number;

## Pseudo code

- `createRng`: mulberry32 auf `uint32`; `next()` ∈ [0,1); `int(n) = floor(next()·n)`.
- Konstruktor: `rng = createRng(seed)`; **immer** zuerst `idx = rng.int(4)`; Karte = `mapId ? MAPS[mapId] : MAPS[idx]`.
  Pfadpunkte `x = cx·40 + 20`, `y = cy·40 + 20`; Pfadzellen wie Original Zeile 74–75.
- `apply`: prüft und lehnt mit `rejected`-Event ab (Reihenfolge Platzieren: `gameOver`, `unknownTower`,
  `outOfBounds`, `path`, `occupied`, `noMoney`). Tower-ID = `state.nextId++`.
  `startWave`: abgelehnt bei `running` (`waveRunning`) oder `over` (`gameOver`); sonst Wellenaufbau wie Spec.
  Angenommene Kommandos → `[state.tick, …]` in die Replay-Liste.
- `step()` in exakt dieser Reihenfolge (wie Original `update`):
  1. Spawn: wenn `running && queue.length`: `spawnTimer -= DT`; wenn `≤ 0`: Spawn erster Typ, `spawnTimer = max(0.25, 0.9 − 0.03·wave)`.
  2. Gegner (nur `hp > 0`): `slowTime -= DT`, `pushCooldown -= DT`; Wachstum; Störimpuls; Bewegung um `speed·(slowTime>0 ? 0.5 : 1)·DT` entlang der Wegpunkte; Leck.
  3. Gegner mit `hp ≤ 0` entfernen.
  4. `lives ≤ 0 && !over` → `over = true`, `running = false`, `queue = []`, Event `gameOver`.
  5. `running && !queue.length && !enemies.length` → Wellenbonus, `running = false`.
  6. Türme: `cooldown -= DT`; `beam = false`; wenn `offTime > 0`: `offTime -= DT`, weiter. Ziel = lebender Gegner in Reichweite mit max. `dist` (D-3).
     dev: Strahl, `hurt(dps·DT)`. Sonst bei `cooldown ≤ 0`: `cooldown = rate`; dualo: `rng.next() < 0.08` → `cooldown = 2`, Event `absent`, kein Schuss; sonst Shot erzeugen.
  7. Shots wie Original Zeile 240–251 (Homing, Treffer, Splash, Slow, Push via `placeAt`).
  8. `tick++`.
- `hurt(e, d)`: ignoriert `hp ≤ 0`; bei `hp ≤ 0` → kill (Belohnung, Score, Feature-Zerfall: 2× `spawnEnemy('story', {dist})`, x-Versatz ±8 wie Original).
- Abstände nur über Quadrate (D-6); Stufenfaktoren aus `LEVEL_DMG`/`LEVEL_RATE`.
- `stateHash`: FNV-1a über eine kanonische Zeichenkette aller `GameState`-Felder (Zahlen via `String(n)`) plus `rng.state()`.
- `runReplay`: neues `Game({seed, mapId})`; für `t = 0 … endTick−1`: alle Kommandos mit Tick `t` anwenden, dann `step()`;
  `matches` = Ergebnis gleich `r.result`. Abgelehnte Kommandos im Replay ⇒ `matches = false`.
- `parseReplay`: prüft `format === 1`, Typen, aufsteigende Ticks, `endTick ≤ 60·60·120` (2 h), max. 10 000 Kommandos.
