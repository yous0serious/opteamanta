# T06: Modus-Wahl, Wellenanzeige, Sieg-Bildschirm

**Phase:** 2 · **Depends on:** T01 · **Covers:** AC-9 · **Who:** hannibal

## Goal

Spieler wählen den Modus, sehen im Challenge den Fortschritt „Welle n / 30“ und erleben einen Sieg-Bildschirm.

## Files

- Change: `index.html`, `src/view/hud.ts`, `src/view/params.ts` (`mode`), `src/view/controller.ts` (Modus bei Neustart behalten), `src/view/GameScene.ts` (Sieg-Overlay, Konfetti), `src/view/style.css`, `tests/e2e/smoke.spec.ts` (neuer Fall)

## Exact values

- Seitenleiste: Umschalter `#mode` mit zwei Buttons „🏁 Challenge (30)“ und „♾ Endlos“; nur vor dem ersten Sprint aktiv; Wechsel startet ein neues Spiel mit demselben Seed.
- `#wave` zeigt im Challenge zusätzlich „· Welle n/30“.
- Sieg-Overlay: Stempel „RELEASE ERFOLGREICH!“ (grün), Zeilen „Moral-Bonus: +X“, „Score: Y“, Hinweis „[Leertaste] Nächstes Programm“; `#big` zeigt „↻ NEUES PROGRAMM“; `#replay` sichtbar.
- URL `?mode=challenge|endless` (Standard `challenge`).
- E2E: `?mode=challenge&seed=…&debug=1`, Zustand per `window.__bd.game.state.wave = 29` + Startgeld, eine Welle spielen → Sieg-Overlay/`#big` „NEUES PROGRAMM“.

## Verify

`npm run build`; `npm run test:e2e` grün.
