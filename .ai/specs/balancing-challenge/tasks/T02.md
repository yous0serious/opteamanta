# T02: Balancing-Hebel als BalanceConfig

**Phase:** 1 · **Depends on:** T01 · **Covers:** AC-8 · **Who:** hannibal

## Goal

Alle Stellschrauben des Balancings liegen in einem Objekt `BALANCE` (v0.2.0) und werden von der Simulation gelesen.
Tools/Tests dürfen per `GameOptions.balance` eine Variante übergeben (Tuning); Spiel und Replays nutzen immer `BALANCE`.

## Files

- New: `src/sim/data/balance.ts`
- Change: `src/sim/game.ts`, `src/sim/data/enemies.ts` (Konstanten wandern nach `balance.ts`), `src/sim/index.ts`

## Interfaces

```ts
export interface BalanceConfig {
  hpGrowth: number;            // Faktor pro Welle (exponentiell): hpScale(w) = hpGrowth^(w−1), per Schleife berechnet
  rewardGrowth: number;        // linear: reward(w) = round(baseReward × (1 + rewardGrowth × (w−1)))
  waveBonusBase: number;       // Bonus nach Welle: base + perWave × w
  waveBonusPerWave: number;
  waveSizeBase: number;        // Gegner pro Welle: base + perWave × w
  waveSizePerWave: number;
  bossHpFactor: number;        // zusätzlicher Faktor nur für den Boss
  startMoney: number;
}
export const BALANCE: Readonly<BalanceConfig>;
```

## Exact values (Startpunkt fürs Tuning = Verhalten v0.1.0 so weit möglich)

`hpGrowth` 1.0 entspricht nicht dem alten linearen Wachstum – das lineare Modell entfällt bewusst. Startwerte für T04:
`hpGrowth 1.2, rewardGrowth 0.15, waveBonusBase 50, waveBonusPerWave 10, waveSizeBase 8, waveSizePerWave 2, bossHpFactor 1, startMoney 200`.

## Pseudo code

- `hpScale` je Welle einmal in `startWave` berechnen (Schleife), im State als `hpScale` ablegen (geht in den Hash).
- Kill-Belohnung: `round(def.reward × (1 + rewardGrowth × (w−1)))` statt `√hpS`.
