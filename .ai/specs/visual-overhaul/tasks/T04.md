**Phase:** 2 · **Depends on:** T02, T03 · **Covers:** AC-6, AC-10 · **Who:** hannibal

## Goal

Das Spielfeld nutzt Texturen; zu Wellenbeginn zeichnet ein Marker-Strich den Pfad nach; die DONE-Spalte sammelt Papierkugeln.

- New: `src/view/logic/donePile.ts` (reine Logik, ohne Phaser), `src/view/render/pile.ts`
- Change: `src/view/render/board.ts`, `src/view/GameScene.ts`

## Interfaces

```ts
// src/view/logic/donePile.ts
export interface PileBall { id: number; x: number; y: number; rot: number; color: string }
export class DonePile {
  constructor(opts: { max: number; area: { x: number; y: number; w: number; h: number }; rand?: () => number });
```

## Exact values

- `max = 60`; Bereich: DONE-Spalte unten, x 720–960, y 470–600 (Kugeln liegen nicht auf dem Pfad – Pfadzellen werden ausgelassen).
- Whiteboard: `prop/whiteboard` als TileSprite; Raster und Spalten wie Spec 1, Spaltenköpfe in Caveat.
- Marker-Pfad: bei `waveStarted` läuft ein Strich in Kartenfarbe in 0,8 s über den Pfad (bei reduzierter Bewegung sofort voll sichtbar).
