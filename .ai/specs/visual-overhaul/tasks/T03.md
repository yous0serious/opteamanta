# T03: Boot/Preload, Font, Effektstufe, Ebenen

**Phase:** 2 · **Depends on:** T01 · **Covers:** AC-8, AC-9, AC-11 · **Who:** hannibal

## Goal

Eine Preload-Szene lädt Atlas und Schrift mit Fortschrittsbalken; die Spielszene hat feste Ebenen mit Filtern je Effektstufe.

## Files

- New: `src/view/PreloadScene.ts`, `src/view/fx.ts`, `src/view/layers.ts`
- Change: `src/main.ts`, `src/view/params.ts` (`fx`, `bench`), `src/view/texts.ts` (`HAND` → Caveat), `src/view/GameScene.ts`

## Interfaces

```ts
// src/view/fx.ts
export interface FxSettings { level: 'high' | 'low'; reducedMotion: boolean; particleScale: number /* 1 | 0.5 */ }
export function readFx(params: Params, mql = matchMedia('(prefers-reduced-motion: reduce)')): FxSettings;
// src/view/layers.ts
export interface Layers { board; pile; under; towers; enemies; shots; particles; texts; overlay } // je Phaser-Container
export function createLayers(scene: Phaser.Scene, fx: FxSettings): Layers; // setzt Schatten-Filter auf towers/enemies, Vignette auf Kamera (nur high)
export function activeFilters(scene: Phaser.Scene): string[]; // für E2E über window.__bd.debug.filters()
```

## Exact values

- Schrift: `import '@fontsource/caveat/600.css'`; vor Szenenstart `document.fonts.load('600 20px Caveat')`.
- Fortschrittsbalken: Marker-Strich über die Breite, Text „Lade Backlog… NN %“.
- `fx=high`: Schatten (x 2, y 3) auf Ebenen `towers` und `enemies`, Kamera-Vignette (0.5, 0.5, 0.9, 0.35). `fx=low`: keine Filter, `particleScale` 0.5.
- `window.__bd.debug.filters()` liefert Namen aktiver Filter (z. B. `['towers:Shadow','enemies:Shadow','camera:Vignette']`).
