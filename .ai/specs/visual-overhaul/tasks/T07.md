# T07: Projektile, Partikel, Filter, Juice

**Phase:** 3 · **Depends on:** T06 · **Covers:** AC-7, AC-8, AC-9 · **Who:** hannibal

## Goal

Treffer, Schüsse und Ereignisse fühlen sich wertig an; Filter und Juice folgen der Effektstufe und reduzierter Bewegung.

## Files

- Change: `src/view/GameScene.ts`, `src/view/render/effects.ts` (→ Phaser-Emitter), `src/view/controller.ts` (nur `hitstop(ms)`: pausiert `advance` ohne Sim-Änderung)

## Exact values

- Projektile: Dualo `proj/dualo`, BA `proj/analyst`, Scrum `proj/scrum` (dreht sich), PPL `prop/pin` mit Schatten; Spuren als Marker-Linie.
- Entwickler-Strahl: Linie + Glow (`#d81b60`, 4) + `proj/code`-Partikel entlang des Strahls.
- Partikel-Emitter (Kenney-Texturen): Konfetti (Kill), Funken (Treffer), Rauch (Splash), Sterne (Upgrade); Anzahl × `particleScale`.
- Game Over: Kamera-ColorMatrix entsättigt (`grayscale(0.85)`) über 600 ms (nur `fx=high`).
- Hitstop: 60 ms bei Boss-Kill; Kamerawackeln wie Spec 1; Wellen-Banner: Marker schreibt Text (Breite 0 → 100 % in 500 ms), steht 1,2 s, blendet aus.
- Reduzierte Bewegung: kein Wackeln, kein Hitstop, Banner statisch eingeblendet.

## Verify

`npm run build`; Screenshots Strahl, Splash, Game Over (high/low); `window.__bd.debug.filters()` bei high/low.
