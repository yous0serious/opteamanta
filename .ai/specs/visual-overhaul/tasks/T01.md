# T01: Asset-Pipeline

**Phase:** 1 · **Depends on:** – · **Covers:** AC-2 · **Who:** hannibal

## Goal

Rohdateien in `assets-src/` werden per `npm run assets` zu einem Phaser-Atlas in `public/assets/`; `npm run check:assets`
erzwingt die Lizenzliste.

## Files

- New: `assets-src/manifest.json`, `assets-src/kenney/toon-characters-1/` (nur genutzte Köpfe/Posen + `License.txt`),
  `assets-src/kenney/particle-pack/` (nur genutzte PNGs + `License.txt`), `tools/build-assets.ts`, `tools/check-assets.ts`,
  `public/assets/CREDITS.md`
- Change: `package.json` (Skripte `assets`, `check:assets`; devDeps `sharp`, `free-tex-packer-core`; dep `@fontsource/caveat`), `.trivy-baseline.json` (Delta in T10)

## Interfaces

`assets-src/manifest.json`:
```json
{ "atlas": "game", "maxSize": 2048, "padding": 2,
  "frames": [ { "name": "head/dualo", "src": "kenney/toon-characters-1/Male adventurer/PNG/Parts/head.png", "scale": 0.75 },
              { "name": "prop/postit", "src": "props/postit.svg", "width": 64, "height": 64 } ] }
```
Ausgabe: `public/assets/game.png` + `game.json` (Phaser-Atlas-Hash-Format, Frame-Namen = `name`).

## Exact values

- Quellen: `https://opengameart.org/sites/default/files/kenney_toonCharacters1.zip`, `…/kenney_particlePack.zip` (Kenneys eigene Uploads, CC0 laut `License.txt`).
- Kopf-Frames je Rolle: `head`, `headFocus`, `headShock` → `head/<rolle>`, `head/<rolle>-focus`, `head/<rolle>-shock`; Rollen-Mapping laut Spec.
- `check:assets`: jede Datei in `public/assets/` (außer `CREDITS.md`) muss in `CREDITS.md` als Zeile vorkommen; Exit 1 sonst.
- Grafik-Assets gesamt ≤ 3 MB (Prüfung in `check:assets`).

## Verify

`npm run assets && npm run check:assets`; Gegenprobe: Dummy-Datei in `public/assets/` → `check:assets` Exit 1.
