# T02: Eigene Requisiten-SVGs

**Phase:** 1 · **Depends on:** T01 · **Covers:** AC-3, AC-10 · **Who:** hannibal

## Goal

Alle Spielobjekte ohne CC0-Vorlage existieren als eigene SVGs im Marker-/Papier-Stil und landen über das Manifest im Atlas.

## Files

- New: `assets-src/props/*.svg`, Einträge in `assets-src/manifest.json`, Zeilen in `public/assets/CREDITS.md` („eigenes Werk“)

## Exact values (Frame-Namen)

| Frame | Inhalt |
|---|---|
| `prop/postit`, `prop/postit-curl` | weißes Post-it (wird eingefärbt) mit Klebestreifen-Schatten; Variante mit gewellter Ecke |
| `prop/paperball` | zerknüllte Papierkugel (weiß, einfärbbar) |
| `prop/magnet-ring`, `prop/magnet-gloss` | Magnet-Ring (weiß, einfärbbar) und Glanz-Overlay |
| `prop/tape` | Klebeband-Kachel 64×32, nahtlos horizontal |
| `prop/whiteboard` | Whiteboard-Kachel 256×256 mit leichter Struktur und Wischspuren |
| `prop/pin` | Pinnnadel (PPL-Projektil) |
| `proj/dualo` (Kaffeebohne), `proj/analyst` („?“), `proj/scrum` (Kreispfeil), `proj/code` (`</>`) | Projektile |
| `sym/req`, `sym/cr`, `sym/story`, `sym/obj`, `sym/feat`, `sym/creep`, `sym/debt`, `sym/boss` | Marker-Symbole: Linien, Pfeilkreis, Puzzle, Zielscheibe, Kiste, Käfer, Geldschein, Elefant |
| `ui/star`, `ui/zzz` | Stufenstern, Schlaf-Zeichen |

Stil: Konturen 3 px `#2b3440`, leicht unregelmäßig; Füllungen weiß/neutral für Einfärbung per Tint.

## Verify

`npm run assets && npm run check:assets`; Kontaktabzug aller Frames als `.tmp/evidence/visual/atlas-sheet.png` (Sichtprüfung).
