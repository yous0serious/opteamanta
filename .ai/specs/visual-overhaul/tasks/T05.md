# T05: Türme als Magnet-Badges

**Phase:** 3 · **Depends on:** T04 · **Covers:** AC-4 · **Who:** hannibal

## Goal

Jeder Turm ist ein Magnet-Badge mit der Rollenfigur und reagiert sichtbar auf Zustände.

## Files

- Change: `src/view/render/entities.ts` (TowerView), `src/view/GameScene.ts`

## Exact values

- Aufbau: `prop/magnet-ring` (Tint = Turmfarbe aus Spec 1) + weiße Scheibe + `head/<rolle>` + `prop/magnet-gloss`; Ø 36 px; Richtungszeiger als kleiner Marker-Pfeil.
- Idle: Kopf wippt ±1,5 px, Periode 2–3 s (zufällige Phase); bei reduzierter Bewegung aus.
- Feuern (`fired`): 120 ms Squash (scaleX 1.15 / scaleY 0.85) + Frame `-focus` für 250 ms; Entwickler: `-focus`, solange `beam`.
- Upgrade: Pop-Tween (1 → 1.3 → 1, 300 ms), Sterne `ui/star` je Stufe > 1 unter dem Badge.
- Außer Betrieb: Frame `-shock`, Ring-Tint `#9e9e9e`, `ui/zzz` schwebt.
- PPL-Aura und Boost-Ring wie Spec 1, in Marker-Optik.
